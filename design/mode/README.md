## November 10 abstract page material

`PageAbstractSource.png` was generated directly in that Figma file using its
image-generation tool (`gpt-image-2.5-flare`), node **24:31**:
https://www.figma.com/design/8ZPSZPK4eJ4ocvy7CA2HpO?node-id=24-31
The original 1024×1024 opaque PNG is retained here. It contains subdued charcoal
diagonal planes and fine grain; there is no reference-addon or dashboard artwork.
It is original generated artwork for this addon, distributed with this repository.

`tools/build_mode_textures.py` converts it to 512×512 RGBA
`Media/Textures/Mode/PageAbstract.tga` with Lanczos downsampling only. It does not
recolor, crop or slice the design. The runtime draws it at 18% opacity over the
existing Figma Surface, tinted #2A2A2A, and beneath the existing static sheen.
This leaves the sidebar at #232323 and keeps the material independent of Global
Texture. It is not applied to controls, other themes or gameplay displays.

Figma layout editing was unavailable at the Starter MCP call limit, and its web
editor was not signed in. The separate image-generation tool succeeded. No
new Figma token/component library or updated composed screen is claimed.

## Original interface assets

### Native capsule correction

`PillSurface.svg` is original repository-native UI geometry: a white 256×64
capsule with radius 32, distributed under the repository license. It is not a
Figma export or reference screenshot asset. `tools/build_mode_textures.py`
validates this simple SVG geometry, rasterizes at 8× resolution and downsamples
the alpha mask with Lanczos to `Mode/PillSurface.tga` (256×64 RGBA). The main
Campfire pilot pills use it without slicing for both the outer gray backing
and the 1.5-unit-inset fill. This replaces stretching the 32×16 toggle sprite.
Switches and other themes retain their existing files. Missing new art falls
back to the existing rounded sprite; source SVG stays out of the runtime package.
Runtime SHA256: `5c904d8257022843a24908fc98a0f5b87d8daa1d5abea86242ef45c35ee3eedb`.

`Mode/HeaderLine.tga` is a native procedural 256×4 white alpha rule, generated by
the same builder. All four alpha rows are identical; a symmetric smoothstep fade
occupies 48 source pixels at each end. Rendering at one UI unit therefore keeps
the same thickness across all content headings. The runtime measures text to
center the rule beneath it. This is repository-native UI geometry, not a Figma
export; only the TGA is packaged. No existing artwork is overwritten.

PNGs were exported through the Figma Plugin API `exportAsync({format:'PNG',
contentsOnly:true})` and `figma.base64Encode`. This preserves transparent alpha;
the generic asset preview export includes the page background and is not used.
Runtime TGAs preserve RGBA pixels except the documented checkbox/logo resampling:
`python tools/build_mode_textures.py` with Pillow. Source PNGs/design files are
outside the addon; only TGAs are included in the runtime package. Texture slicing
uses the existing native helper with 12px margins on panels and 10px on buttons;
small checkbox/switch sprites do not use slicing.
Missing surfaces fall back to readable neutral fills; missing borders stay clear.
Small checkbox/switch sprites now bypass slicing so the full rounded silhouette
is drawn. Their runtime paths changed after the owner reported square controls;
the original source PNGs remain untouched. All runtime canvases are powers of two.
Large surfaces and control buttons retain their existing slices. Surface
6:32 also includes subtle neutral sheen/detail layers. The Starter tool-call limit
was reached after these assets were exported; the composed screen could not be
updated with the final header/spacing refinement in this pass.

`Logo.png` is the addon owner's supplied **ptg addon.png**, with background removal
performed through ImageGen. The second cutout was selected after inspecting alpha
and its actual 38px presentation against the #2B2B2B canvas; the faint fully/near
transparent export pixels are not an opaque backing. The source PNG is retained;
the builder downsamples it to a 128px RGBA TGA for the mode header. This owner-supplied
brand asset is separate from the original Figma control artwork. Logo, settings,
frame names and metadata in the other themes are unchanged.

The composed preview remains editable text, instances and frames. It uses Lato
Regular/Bold, verified in the Figma font catalog. No flattened UI image is embedded
as a substitute for the editable preview or runtime UI.
