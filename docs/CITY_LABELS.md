# City Labels

Quality of Life -> City Labels puts small colored dots, with optional names, on
the world map for trainers and town services: class and profession trainers,
weapon masters, banks, auction houses, inns, flight masters, guild masters and
transmogrifiers, and optionally stable masters, mailboxes, repair vendors and
other vendors. The module is off by default. Hovering a dot lists the NPCs there
and credits the data source; clicks pass through to the map.

## Behavior

- Class trainers show for your class only unless **All Classes** is on; class
  trainer dots use the class color. Labels belonging to the other faction are
  hidden unless **Other Faction** is on. When the client does not report your
  faction or class, both are shown rather than guessed.
- Mailboxes are dots without names. **Show Names** turns all map text off.
- **Dot Size** (8-24) and **Name Size** (8-16) apply on the next map draw. Dots
  keep the same on-screen size at every map zoom.
- Nothing is recorded or saved besides these preferences. Settings use
  `PTGToolsDB.modules.cityLabels` and are covered by profile validation.

## Implementation and API use

`Modules/CityLabelsMap.lua` adds one standard data provider to `WorldMapFrame`
and draws through `AcquirePin` / `RemoveAllPinsByTemplate` with the
`PlayTheGameToolsCityLabelsMapPinTemplate` XML template, the same native pin
pool contract Dungeon Loot uses. These calls, `MapCanvasDataProviderMixin` and
`MapCanvasPinMixin` (`SetScalingLimits`, `SetIgnoreGlobalPinScale`,
`UseFrameLevelType`, `SetMouseClickEnabled`) were checked against the
[Forever map canvas source](https://github.com/Gethe/wow-ui-source/tree/forever/Interface/AddOns/Blizzard_MapCanvas).
An unknown frame-level type falls back to the default level there.

- The world map addon is never force-loaded. If it is not loaded yet, the provider
  attaches on its `ADDON_LOADED`; attaching waits for `PLAYER_REGEN_ENABLED` when
  in combat. Pins are plain frames, so redraws while the map is open are safe.
- Disabling the module removes its pins; the provider stays registered and draws
  nothing, so the map's provider list is never changed in combat.
- A drawing error is printed once, shown as **Map Status** on the settings page,
  and leaves the rest of the map working.

## Data

`Modules/CityLabelsData.lua` is generated by `tools/build_city_labels.py` from
the [EG Link WoW: Forever dataset](https://github.com/JIVESCORP/eg-link-output-wowf)
(Data from Efficient Games, CC BY 4.0). The attribution, source commit, builds
and changes are in the file header and THIRD_PARTY_NOTICES.md. The generator:

- reads only released-client builds (1.60.1.70790 onward), so coordinates match
  the live maps; the newest build that recorded an NPC wins;
- reads `npcs`, `trainers`, `vendors` and `creature_details.enUS`; roles come from
  the NPC's window types and title, and a trainer whose class or profession
  cannot be recognized is skipped and listed, not guessed;
- reduces each NPC's recorded player positions to one point on the map where it
  was seen most, then merges same-service points within 12 yards (50 for
  auction houses and banks, so a hall's tellers are one label) and lists an
  adjacent guild vault with its bank.

Positions are where players stood when they used the service, so labels sit
near the NPC, not exactly on it. Coverage is what players have recorded:
Stormwind, Orgrimmar, Thunder Bluff and Undercity are well covered; Ironforge
and Darnassus currently have only a few labels.

To refresh, clone the dataset, check out a commit and regenerate, then update
the commit in THIRD_PARTY_NOTICES.md (both copies):

```sh
git clone https://github.com/JIVESCORP/eg-link-output-wowf eg-data
git -C eg-data checkout <commit>
python tools/build_city_labels.py eg-data <commit>
python tests/city_labels.py
```

The generator is deterministic and never downloads anything itself.

## Checks

`python tests/city_labels.py` covers the data shape and attribution, filters,
deferred and combat-safe attaching, pin drawing and tooltip, disable/redraw,
failure reporting, the settings page and persistence against a mock of the
inspected map canvas. It is not native confirmation.

Native checks L1-L7 (Navigation, Action, Required state, Confirmation) are in
[TESTING.md](../TESTING.md#city-labels). New TOC files need one client restart.
